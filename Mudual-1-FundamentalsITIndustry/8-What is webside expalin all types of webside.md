# What is a Website?

A website is a collection of web pages that are connected together and stored on a web server. These pages are accessed through a browser using a specific domain name or URL.

A website can contain text, images, videos, links, forms, and other digital content.

## Examples of Websites

- Google
- Facebook
- YouTube
- Amazon
- College website
- Business website

## Purpose of a Website

A website is used to:
- share information
- sell products or services
- provide online education
- communicate with customers
- build brand identity
- offer online support and services

## Types of Websites

### 1. Static Website
A static website contains fixed content that does not change often.

Features:
- Simple design
- Pages are written in HTML and CSS
- Content is same for every user
- Easy and cheap to build

Examples:
- Company profile website
- Personal portfolio website

### 2. Dynamic Website
A dynamic website changes its content based on user interaction, database values, or time.

Features:
- Uses server-side programming
- Connects with databases
- Shows personalized data
- Often used for online applications

Examples:
- Facebook
- E-commerce sites
- Banking portals

### 3. E-commerce Website
An e-commerce website is used to buy and sell products online.

Examples:
- Amazon
- Flipkart
- eBay

### 4. Educational Website
An educational website provides learning resources and online classes.

Examples:
- Coursera
- Udemy
- School websites

### 5. Business Website
A business website is used by companies to present their services, products, and contact information.

Examples:
- Local shop website
- IT company website

### 6. Blog Website
A blog website is used to publish articles, tutorials, stories, and opinions.

Examples:
- WordPress blogs
- Tech blogs

### 7. Social Media Website
A social media website allows users to connect and communicate with each other.

Examples:
- Facebook
- Instagram
- Twitter

### 8. News Website
A news website provides latest updates and current affairs information.

Examples:
- BBC
- CNN
- Times of India

### 9. Government Website
A government website provides public information and services related to government departments.

Examples:
- Official city portal
- Tax or passport services

### 10. Portfolio Website
A portfolio website is used by individuals to showcase their work, skills, and projects.

Examples:
- Designer portfolio
- Developer portfolio

### 11. Forum Website
A forum website allows users to ask questions and discuss topics with others.

Examples:
- Quora
- Stack Overflow

### 12. Search Engine Website
A search engine website helps users find information on the internet.

Examples:
- Google
- Bing
- Yahoo

## Difference Between Website and Webpage

- Website: A collection of many web pages under one domain
- Webpage: A single page within a website

Example:
- website = company website
- webpage = home page, about page, contact page

## Summary
A website is a collection of connected web pages that are accessed through the internet. It can be static or dynamic and may serve different purposes such as education, business, shopping, entertainment, blogs, news, and social networking. Each type of website is designed for a specific function and audience.

## Short Definition
Website = A set of related webpages available on the internet and accessed through a browser.
