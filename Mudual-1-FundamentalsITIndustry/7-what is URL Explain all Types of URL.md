# What is a URL?

URL stands for Uniform Resource Locator. It is the address used to locate a resource on the internet, such as a web page, image, file, or document.

A URL tells the browser where a specific resource is located and how to access it.

Example:
https://www.google.com/search?q=software

## Parts of a URL

A URL usually has the following parts:

### 1. Protocol
It tells the browser which communication method to use.

Examples:
- http://
- https://
- ftp://

### 2. Domain Name
This is the website name or server address.

Example:
www.google.com

### 3. Path
It identifies the specific page or file on the website.

Example:
/about-us
/products/laptop

### 4. Query String
This is used to send additional information to the server.

Example:
?q=software

### 5. Fragment
It points to a specific section inside a page.

Example:
#introduction

## Types of URL

### 1. Absolute URL
An absolute URL contains the complete address of a resource, including protocol, domain name, and path.

Example:
https://www.example.com/about.html

### 2. Relative URL
A relative URL is a partial address that is relative to the current page or document.

Example:
/about.html

### 3. Static URL
A static URL is fixed and does not change frequently.

Example:
https://www.example.com/contact

### 4. Dynamic URL
A dynamic URL contains parameters or data generated by the server.

Example:
https://www.example.com/products?id=101

### 5. HTTP URL
This type uses the HTTP protocol.

Example:
http://www.example.com

### 6. HTTPS URL
This uses the secure version of HTTP and encrypts communication.

Example:
https://www.example.com

### 7. FTP URL
FTP is used to transfer files between computers.

Example:
ftp://files.example.com/download

### 8. Mailto URL
This opens an email client to create a new email.

Example:
mailto:info@example.com

### 9. File URL
A file URL points to a file stored on a local system or network.

Example:
file:///C:/Users/Name/Desktop/report.pdf

### 10. Data URL
This is a URL that stores data directly within the URL string.

Example:
data:text/plain;base64,SGVsbG8=

## Importance of URL

- Helps locate websites and resources
- Identifies files and pages on the internet
- Used by browsers to fetch web content
- Enables navigation between pages

## Example of a URL with Explanation

https://www.example.com/products/laptop?id=101#specs

Breakdown:
- https:// = protocol
- www.example.com = domain name
- /products/laptop = path
- ?id=101 = query string
- #specs = fragment

## Summary
A URL is the address used to access a resource on the internet. It may be absolute, relative, static, dynamic, HTTP, HTTPS, FTP, mailto, file, or data URL depending on its purpose. URLs are essential for browsing the web and locating online resources.

## Short Definition
URL = The address used to locate information or resources on the internet.
